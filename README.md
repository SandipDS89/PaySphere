# \# PaySphere — Digital Banking \& Wallet Simulator

# 

# PaySphere is a simulated digital banking and wallet application built with \*\*Python, Flask, PostgreSQL, and SQLAlchemy\*\*. It simulates common wallet operations such as account creation, deposits, withdrawals, transfers, and transaction history.

# 

# > ⚠️ \*\*Disclaimer:\*\* This is a learning/portfolio project. It does not connect to real banks, payment gateways, or real money.

# 

# \## 🚀 Features

# 

# \- User registration and secure login

# \- Session-based authentication

# \- Wallet/account creation

# \- Deposit and withdrawal

# \- Money transfer between accounts

# \- Balance validation

# \- Transaction history

# \- Atomic database transactions using COMMIT/ROLLBACK

# \- REST APIs for core operations

# 

# \## 🧪 QA \& Testing

# 

# The project was also used for practical software testing and automation.

# 

# \- Functional and validation testing

# \- API testing with \*\*Postman\*\*

# \- Database testing with \*\*PostgreSQL\*\*

# \- Automated testing with \*\*pytest\*\*

# \- UI testing with \*\*Selenium\*\*

# \- Page Object Model (POM)

# \- Regression testing

# \- HTML test reports

# 

# \## 🛠️ Tech Stack

# 

# \*\*Application:\*\* Python, Flask, PostgreSQL, SQLAlchemy, HTML, CSS, Bootstrap, JavaScript, Jinja2

# 

# \*\*Testing:\*\* pytest, Selenium, Postman, PostgreSQL
