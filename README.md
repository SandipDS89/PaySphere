# PaySphere — Digital Banking & Wallet Simulator

A simulated digital wallet/banking application built as a learning project to practice Python, Flask, PostgreSQL, and full-stack web development fundamentals.

⚠️ This is a simulation only. No real banks, payment gateways, or real money are involved.

## Features

- User registration with validation and password hashing
- Session-based login/logout with route protection
- Wallet/account creation with unique account numbers
- Deposit, withdraw, and transfer money between accounts
- Atomic database transactions (COMMIT/ROLLBACK) for transfers
- Transaction history with filtering by account
- REST API mirroring all core web functionality

## Tech Stack

- **Backend:** Python, Flask
- **Database:** PostgreSQL, SQLAlchemy (ORM)
- **Frontend:** HTML, CSS, Bootstrap, Jinja2 templates
- **API:** Flask REST API (JSON)
